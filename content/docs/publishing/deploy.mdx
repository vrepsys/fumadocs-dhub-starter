---
title: Deploy your site
description: Deploying the starter to Vercel, Netlify, or any Node.js host.
---

This starter is a standard Next.js application, so it deploys anywhere Next.js runs.

## Vercel

Import the repository at [vercel.com/new](https://vercel.com/new) and deploy with the default settings. Every push to your main branch triggers a production deploy, including pushes made from Dhub.

## Netlify

Import the repository at [app.netlify.com](https://app.netlify.com) with the build command `next build`. The Netlify Next.js runtime handles the rest.

## Anywhere else

```bash
npm install
npm run build
npm run start
```

<Callout type="success" title="Tip">
  Combine a pull-request workflow in Dhub with preview deployments to review content changes on a live site before merging.
</Callout>
