---
title: Steps
description: Numbered steps in Dhub, for tutorials and setup guides where the order matters.
---

Steps turn a procedure into a numbered sequence. Each step starts with a heading and holds any content under it. Type `/steps` to insert a block.

<Steps>
<Step>

### Add a step

Press Enter on an empty line at the end of a step to start the next one. The numbers follow along.

</Step>

<Step>

### Fill it in

A step holds anything a page does: text, lists, callouts, tabs, and code.

```bash
npm run dev
```

</Step>

<Step>

### Rearrange

Click the number of a step to add a step below it, move it up or down, or delete it.

</Step>
</Steps>

In your repo, steps are stored as the Fumadocs `<Steps>` and `<Step>` components, nothing Dhub-specific.

<Callout type="idea" title="Try it">
  Add a fourth step above, then move it to the top from the menu on its number.
</Callout>
