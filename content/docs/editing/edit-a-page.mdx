Open any page in Dhub and click into the text to start writing. The editor works with **blocks**: paragraphs, headings, callouts, code blocks, images, and more.

## The slash menu

Type `/` on an empty line to open the block menu. A few to try:

- `/callout` inserts a highlighted callout box

- `/tabs` inserts a tab group

- `/code` inserts a code block

- `/image` inserts an image block

- `/table` inserts a table

## Page titles

In Fumadocs the page title lives in the frontmatter, not in the body. Dhub shows it as the editable heading at the top of the page and writes it back to the `title` field for you.

## What lands in your repo

Everything is stored as standard Fumadocs MDX. This page, for example, is `content/docs/editing/edit-a-page.mdx` in your repository, exactly as you would have written it by hand.
